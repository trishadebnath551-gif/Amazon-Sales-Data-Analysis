Amazon Sales Data Analysis

Project Overview

This project focuses on analyzing Amazon sales data using SQL and Power BI to understand sales performance, order patterns, product categories, and business trends.

The project involves querying and analyzing sales data using SQL and presenting meaningful insights through an interactive Power BI dashboard.

Tools & Technologies

- SQL (MySQL): Data querying, filtering, aggregation, and analysis.
- Power BI: Dashboard creation and data visualization.

Key Analysis Areas

- Sales performance and order analysis
- Product category analysis
- Order status and fulfillment analysis
- Shipping service-level analysis
- Geographical sales distribution
- Quantity and revenue analysis
- Trends and business performance insights

Project Objectives

- Analyze Amazon sales data to identify meaningful patterns.
- Understand order distribution and sales performance.
- Explore product categories and geographical trends.
- Present business insights through interactive visualizations.

Project Structure

- "SQL/" – SQL queries used for data analysis.
- "Power BI/" – Power BI dashboard file and report screenshots.
- "Dataset/" – Dataset used for the analysis (if shareable).

Key Learnings

- Writing SQL queries for real-world data analysis.
- Working with sales datasets.
- Analyzing business performance using SQL.
- Creating interactive dashboards using Power BI.

Conclusion

This project demonstrates the use of SQL and Power BI to transform raw sales data into meaningful business insights and visual reports.
